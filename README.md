# Site da MOVA

Site institucional da **MOVA Empresa Júnior** — de Fisioterapia, Esporte e Movimento (UFCSPA).

## O que tem no site

- **Sobre a MOVA** — quem somos, trajetória por ano e números em destaque.
- **Serviços** — ginástica laboral, massoterapia, ergonomia, planos de bem-estar e mais.
- **Eventos** — galeria de fotos e vídeos (jornada, acolhe, corridas, minicursos etc.).
- **Equipe** — membros carregados automaticamente de uma planilha do Google.
- **Apoiadores** — faixa com os logos de quem caminha com a MOVA.
- **Contato** — meios de contato direto com a MOVA.

## Estrutura

```
index.html        → página única com todas as seções
css/style.css     → estilos
js/main.js        → interações (galerias, formulário, membros)
assets/           → imagens, vídeos, ícones e logos
```
